# 西南交大 · 共享单车轨迹可视化

基于成都市公共数据开放平台的共享单车订单数据，对**西南交通大学犀浦校区及周边区域**做晚高峰轨迹模拟与可视化。

## 交互

| 操作      | 效果                                            |
| ------- | --------------------------------------------- |
| 滚轮      | 以光标为中心缩放地图。                                   |
| 左键拖动    | 平移地图。                                         |
| 鼠标悬停时间轴 | 在光标上方显示该位置对应的时间（HH:MM:SS），并用竖线标出落点，方便点击到特定时刻。 |
| 左键双击位置点 | 高亮该订单，右侧显示距离、持续时间、方向、起止时间；地图上标注「起 / 终」。       |
| 时间轴拖动   | 定位到任意时刻，轨迹位置按时间插值。                            |
| 空格      | 播放 / 暂停。                                      |
| ← / →   | 时间前后移动一个单位（单位 = 当前倍速的秒数）                      |
| 倍速按钮    | 弹出菜单选择 1×–60×（1× = 现实 1 秒/秒）                  |

## 实现要点

**轨迹**：只有起终点，没有实时GPS，这是数据集项目决定的。位置通过按匀速行驶在路径上插值来模拟；忘记还车订单改用8km/h的运动时长计算进度；路径优先使用OSM路网最短路径。

**地图**：通过map.osm文件解析为水域、绿地、建筑、四级道路、铁路，用 Canvas 以局部米制坐标绘制，缩放不模糊。

**昼夜亮度**：18:00 起随时间逐渐压暗（夜间遮罩 0.02 → 0.28），并叠加日落的暖色余晖。（但是没有什么用，因为数据绝大多数都在夜间）

## 数据清洗：按道路拟合速度

速度 = 贴路路径长度 ÷ 订单时长，单位为 km/h。这个速度是模拟速度，因为缺乏实时GPS数据，所以无法获得真实速度。

| 速度        | 处理                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------ |
| > 25 km/h | 视为坏数据，剔除——否则你会看见328个闪电飞人。                                                                                          |
| 8–25 km/h | 正常，按实际时长匀速走完。                                                                                                      |
| < 8 km/h  | 视为“可能忘记还车”（2,451 条）：按 **8 km/h** 沿拟合道路走完全程；到达后轨迹头的点变成**白色**并静止在终点，轨迹在 **2 秒**（1× 流速）内淡出，白点保留到订单实际结束（t1）；双击白点可查看详情。 |

## 坐标系说明

经纬度.txt 的角点和订单坐标都是 GCJ-02（高德/腾讯系），而OSM底图是WGS84，所以经过了一轮转换。

区域：通过脚本把角点转成 WGS84（向西约 215 m、向北约 286 m）。

订单：通过脚本在筛选前把起终点转成 WGS84，并写回 CSV。

## 已知限制

贴路路径是**路网最短路径**，不是真实骑行轨迹；实际骑行可能与最短路径不同；

297 条订单因端点离路网过远/不连通，回退为直线；

少数订单持续时间异常长（最长 11 小时），已按忘记还车规则处理；

数据仅 2022-12-01 一个晚间时段（18:01 ~ 次日 02:27），不能做日/周对比。
